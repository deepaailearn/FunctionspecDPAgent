===========================================================
Agent Learning Guide: Excel → SQL Mapping
===========================================================

1. Target Table & Target Column
   - Excel Tab : Mapping Columns
   - Excel Columns: LogicalTableName, LogicalColumnName, PhysicalTableName, PhysicalColumnName
   - Rule: Always use PhysicalTableName + PhysicalColumnName as the SQL target.
   - Example: AR_CSTMR_LOAN_AR_V

2. Source Table & Source Column
   - Excel Tab : Mapping Columns
   - Excel Columns: DirectSourceColumns,Consider only when Logic column is Automated,Left Outer Join,Calculation,Constant,One to One.Leave other conditions
   - Rule: Always use DirectSourceColumns as SourceTableName.SourceColumnName as the SQL Source column
   - Example: STA_CDS_SS_FIN_IN_AR_LOAN_V.DEAL_ID_SRC

3.Joining Condition
   - Excel Tab : Mapping Tables,Mapping Columns
   - Excel Columns: Physical Table Name,Direct Source Table(s)
   - Rule: Always use Direct Source Table(s) to get joining condition for Source table
   - Example: STA_CDS_SS_FIN_IN_AR_LOAN_V CST_LOAN join
	      STA_CDS_SS_THALER_AR_CL_ZID02_V TGT_LOAN 
              on CST_LOAN.DEAL_ID_SRC = TGT_LOAN.NUMCPT

4.Filter Condition
   - Excel Tab : Mapping Tables
   - Excel Columns: Direct Source Description
   - Rule: Always use Direct Source Description to get filter condition for Source table
   - Example: where DEL_IN_SRC_STM_F = 0
            AND VLD_FROM_TMS <= to_timestamp('2026-07-30 00.00.00','YYYY-MM-DD HH24.MI.SS'
	 VLD_TO_TMS > to_timestamp('2026-07-30 00.00.00','YYYY-MM-DD HH24.MI.SS') 
  

5. Mapping Logic
   - Excel Columns: Logic, DirectSourceDescription
   - Rule: Convert Logic into SQL expressions (joins, concatenations, filters).
   - Example: Concatenate HS_SRC_CD || '|' || HS_SRC_KEY

6. Data Type & Constraints
   - Excel Columns: DataType, Length, Precision, Null, Key
   - Rule: Use these for CREATE TABLE or schema validation.
   - Example: NUMBER(20,0) NOT NULL PRIMARY KEY

7. Business Context
   - Excel Column: Description
   - Rule: Include as SQL comments for clarity.
   - Example: -- Flag indicating whether the loan is currently active

Example Conversion
===========================================================

Excel Row:
- Target: AR_CSTMR_LOAN_AR_V.MKT_PD_TP_CD
- Source: STA_CDS_SS_FIN_IN_AR_LOAN_V.MKT_PD_TP
- Logic: Map MKT_PD_TP_CL_FIN_IN.' & MKT_PD_TP
         if MKT_PD_CD is null then this field is not populated 

Generated SQL:
-- To get Marketing Product Type Code
INSERT INTO AR_CSTMR_LOAN_AR_V (MKT_PD_TP_CD)
SELECT case when MKT_PD_TP IS NOT NULL THEN 'MKT_PD_TP_CL_FIN_IN.'||MKT_PD_TP END AS MKT_PD_TP_CD
FROM STA_CDS_SS_FIN_IN_AR_LOAN_V

Agent Workflow Summary
===========================================================
1. Read Excel row → Extract PhysicalTableName + PhysicalColumnName
2. Check source mapping → Use DirectSourceColumns or Logic
3. Apply transformation → Convert Logic into SQL
4. Get Source table name join condition from Mapping tables tab
5. Get source table filter where condition from Mapping tables tab of excel
4. Generate SQL → Build SELECT mapping query for each target column
5. Annotate → Add Description as comments
